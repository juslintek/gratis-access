== Description ==

Membership and content restriction with access levels, drip content, and per-user gating.

Part of the Gratis suite — a collection of free, no-upsell WordPress plugins.

**Features:**

* Tiered access levels with a configurable default
* Per-post and per-section content restriction
* Drip (time-delayed) content release
* Customisable logged-out and upgrade-required messages
* Grant access to any user from the settings screen

**Philosophy:**

Everything is free. No "Pro" version, no locked features, no nag screens. Optional managed cloud services may be offered separately to cover infrastructure costs.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Configure it from its settings screen in the WordPress admin.
